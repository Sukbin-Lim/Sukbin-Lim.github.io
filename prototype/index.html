LLM Accelerator

Adelia

4 nm LLM inference accelerator — streamlined dataflow + dual-mode parallelism

Matches external memory bandwidth to an LLM-optimized compute engine through a Streamlined Dataflow and Systolic Parameter Path, and dynamically switches between context-mode and batch-mode parallelism — reaching up to 91% memory-bandwidth utilization on end-to-end LLM inference for models up to 30B parameters.
